# maha-abid.github.io

My portfolio site — [maha-abid.github.io](https://maha-abid.github.io)

Hand-written HTML and CSS. No framework, no build step, no JavaScript libraries.
The whole page is about 20KB.

## Structure

```
index.html   — the page
style.css    — all styles (light + dark, responsive)
```

## Local preview

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000
